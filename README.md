# Uni-Bond Project

# 

# Uni Bond is a full-stack web application designed to connect university students, instructors, and company administrators through opportunities, profiles, tasks, and interaction features. The system provides a platform where users can manage opportunities, user profiles, requests, and role-based workflows.

# 

# \## 🚀 Features

# 

# \- User role management for students, instructors, and company admins

# \- Opportunity management

# \- User profile management

# \- Task and request workflow

# \- Post interaction features

# \- Backend API documentation with FastAPI Swagger UI

# \- PostgreSQL database integration

# \- Alembic database migrations

# \- React frontend with Vite

# 

# \## 🛠️ Tech Stack

# 

# \### Frontend

# \- React

# \- Vite

# \- TypeScript

# \- CSS / UI Components

# 

# \### Backend

# \- FastAPI

# \- Python

# \- PostgreSQL

# \- SQLAlchemy

# \- Alembic
